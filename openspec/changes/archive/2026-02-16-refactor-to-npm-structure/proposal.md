## 为什么

当前项目目录结构混乱，存在 `src/` 和 `cce/` 两个源代码目录，不符合常规 npm 项目规范，导致开发体验不佳且难以维护。

## 变更内容

- **BREAKING**: 将 `cce/` 目录下的源代码移到根目录的 `src/` 目录
- 移除根目录的空目录 `bin/`（如有）
- 统一项目结构，保持标准的 npm 布局
- 更新 `package.json` 中的相关路径配置

## 能力

### 新能力
- `standard-npm-structure`: 建立符合 npm 惯例的标准项目目录结构

### 修改的能力
- 无（仅涉及重构，不改变功能需求）

## 影响

- `cce/` 目录将被移除或重构为其他用途
- 所有源代码路径将统一到 `src/` 下
- 构建脚本中的路径引用需要更新
- 可能影响开发者本地开发环境配置
