### Task 2: 集成模板到 Provider Add 命令

<read_first>
- src/commands/provider.ts (目标文件 — 修改)
- src/core/sourceTemplates.ts (模板定义)
</read_first>

<action>
修改 `src/commands/provider.ts` 中的 `providerAddCommand()` 函数：

1. 在文件顶部引入：`import { getTemplate } from '../core/sourceTemplates.js';`

2. 重构交互流程为两阶段：
   - **Phase 1**: 先询问 source 选择（使用已存在的 SOURCE_OPTIONS）
   - **加载模板**: `const template = getTemplate(source);` — 加载模板准备默认值
   - 展示模板描述（如有）：`console.log(\`  \${template.description}\`);`
   - **Phase 2**: 后续字段使用模板默认值（inquirer 的 `default` 属性）：
     - `type` → `default: template.type`
     - `displayName` → `default: template.displayName`
     - `baseURL` → `default: template.baseURL || undefined`（custom 时为空）
     - `models` → `default: template.models.length > 0 ? template.models.join(', ') : undefined`
     - `defaultModel` → `default: template.defaultModel || undefined`
     - `apiKey` → 无 default（强制输入）

3. 边界处理：
   - 如果用户自定义 models 后 defaultModel 不在列表中，自动添加（已有逻辑）
</action>
