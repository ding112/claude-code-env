    4. **新增：用户配置验证函数**（私有，不导出）：
       ```typescript
       function isValidSourceTemplate(obj: unknown): obj is SourceTemplate {
         if (!obj || typeof obj !== 'object') return false;
         const t = obj as Record<string, unknown>;
         return (
           typeof t.source === 'string' &&
           typeof t.displayName === 'string' &&
           typeof t.type === 'string' &&
           typeof t.baseURL === 'string' &&
           Array.isArray(t.models) &&
           t.models.every((m: unknown) => typeof m === 'string') &&
           typeof t.defaultModel === 'string' &&
           typeof t.description === 'string'
         );
       }

       function loadSources(): Record<SourceType, SourceTemplate> {
         try {
           const raw = fs.readFileSync(SOURCES_USER_FILE, 'utf-8');
           const parsed = JSON.parse(raw) as Record<string, unknown>;

           if (
             typeof parsed === 'object' &&
             !Array.isArray(parsed) &&
             Object.entries(parsed).every(
               ([key, val]) =>
                 validSources.includes(key as SourceType) &&
                 isValidSourceTemplate(val)
             )
           ) {
             return parsed as Record<SourceType, SourceTemplate>;
           }

           logger.warn(
             `用户 sources.json 格式无效，将使用内置模板。路径: ${SOURCES_USER_FILE}`
           );
         } catch (err) {
           if ((err as NodeJS.ErrnoException).code !== 'ENOENT') {
             logger.warn(
               `加载用户 sources.json 失败: ${(err as Error).message}，将使用内置模板`
             );
           }
         }

         return { ...BUILTIN_SOURCES };
       }
       ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem -> sourceTemplates module | Sources JSON files loaded from filesystem cross into application memory |
| user config ~/.config/cce/sources.json | Untrusted user-written JSON file loaded at application startup |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | sources.json loader (user config) | mitigate | `loadSources()` validates every entry: checks each key is a valid `SourceType`, each value has correct field types (string, string[], etc.). Invalid structure triggers `logger.warn()` + fallback to built-in. |
| T-09-02 | Tampering | sources.json loader (user config) | accept | User config with malicious data (e.g., phishing baseURL) could show misleading prefills. Accepted because: (a) templates only pre-fill forms, never auto-save, (b) user reviews and confirms before saving, (c) config file is local with 0o700 permissions, and (d) this is a power-user feature — user editing this file is responsible for its contents. |
| T-09-03 | Denial of Service | JSON.parse (user config) | mitigate | `JSON.parse` is wrapped in try-catch. Malformed JSON or deeply nested objects are caught, warning logged, fallback to built-in. No crash or hang. |
| T-09-04 | Elevation of Privilege | SOURCES_USER_FILE path in config.ts | mitigate | Path is hardcoded via `path.join(os.homedir(), '.config', 'cce', 'sources.json')`, not derived from user input. No path traversal vector. |
</threat_model>
